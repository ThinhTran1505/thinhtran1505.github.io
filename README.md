# Personal Website

Static personal website (HTML + CSS + vanilla JS) hosted on GitHub Pages at https://thinhtran1505.github.io/

## Edit content
- Each page's content lives in its own HTML file: `index.html`, `education.html`, `experience.html`, `publication.html`, `awards.html`, `tracking.html`.
- Search for `Your Name`, `20XX` and `href="#"` to find placeholders.
- Typewriter phrases: `js/app.js` (`const phrases`).
- Images: `images/me.png` (avatar), `images/favicon.png`, logos in `images/education/`, `images/experience/`, teasers in `images/publications/`.
- Tracking page: set `data-github-user` / `data-leetcode-user` on `#tracking` in `tracking.html`.

## Run locally
```bash
python -m http.server 8000
```
Open http://localhost:8000
